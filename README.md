# FreeMyFinance

FreeMyFinance 是面向 Android 和 iOS 的个人记账应用，目前处于首个开发版本。

## 已实现

- 创建账户并设置初始余额（可为负）；支持 CNY、HKD、USD、EUR 和 GBP，各币种以最小单位整数计算，分别汇总。
- 手动记录、编辑和删除收入与支出，按账户、日期和关键词筛选。
- 添加、编辑、删除账户（存在关联账单时不可删除），并在账户间转账（跨币种时需填写实际到账金额）。
- 按年份、月份、账户及支出分类查看统计；设置每月人民币预算。
- 账单分类可以输入自定义名称，并可重命名或合并；支持导出通用 CSV 和可筛选的 Excel（不等同银行账单导入）。
- 支持每月周期规则，可在应用内手动生成到期账单；不发送后台系统通知。
- 查看账户余额、当月收支和最近账单。
- 添加账户时可填写 HTTPS 卡面图片地址；加载失败时显示默认图标。
- 可通过右上角菜单导出、恢复备份；恢复会替换当前账本；支持密码加密备份，未加密备份也可选择导出。
- 账目保存在当前设备，不需要登录；卸载应用或清除应用数据可能导致数据丢失。支持导出 JSON 备份并从备份恢复；目前没有云同步，本地账本没有加密，请妥善保存备份。

图片地址由使用者自行提供，仓库不包含第三方卡面；使用前请确认图片授权。尚未集成 AirCards 目录。

## 开发

需要 Flutter SDK 和 Android SDK。iOS 构建需要 macOS 和 Xcode。

```powershell
flutter pub get
flutter analyze
flutter test
flutter run
```

在此工作站，可以先运行 `. E:\DevEnv\Android\Enable-FlutterEnvironment.ps1`，再执行以上命令。

## 状态

这是开发中的版本，尚未发布；未完成真机和 iOS 构建验证。账户余额由初始余额和手工录入的账目计算，不连接银行，也不会自动同步交易。

### Android 正式签名

将 `android/key.properties.example` 复制为 `android/key.properties` 并填写自己的签名密钥信息，密钥文件及配置应妥善保管，不能提交到仓库。没有配置签名时，release 构建不会使用调试密钥。
