# FreeMyFinance

FreeMyFinance 是面向 Android 和 iOS 的个人记账应用，Android 正式版已发布。

## 已实现

- 创建账户并设置初始余额（可为负）；支持 CNY、HKD、USD、EUR 和 GBP，各币种以最小单位整数计算，分别汇总；可设置非实时手动汇率，估算人民币总值。
- 手动记录、编辑和删除收入与支出，按账户、分类、日期和关键词筛选。
- 添加、编辑、删除账户（存在关联账单时不可删除），并在账户间转账（跨币种时需填写实际到账金额）。
- 按年份、月份、账户及支出分类查看统计；设置每月人民币预算。
- 设置中的分类管理可分别新增收入和支出标签，并同步到“记一笔”；记账时输入的新分类也会自动加入。分类可重命名或合并，并随本地备份迁移；支持导出通用 CSV 和可筛选的 Excel（不等同银行账单导入）。
- 支持每月周期规则，可在应用内手动生成到期账单；可单独启用安卓每日记账提醒，实际送达受通知权限与省电策略影响。
- 查看账户余额、可切换月份的日历收支视图和最近账单；每天分别标出收入与支出。
- 统计页可使用个人 DeepSeek API Key 分析当前筛选范围的收支与分类汇总。右上角“工具与设置”中的“AI 分析设置”可保存 Key、编辑或恢复预设提示词。用户确认后才发送汇总；不发送卡号、账户名、备注或逐笔账单。调用可能产生 API 费用。
- AI 分析结果可在统计页的“历史记录”中查看和删除，包含当时的提示词与汇总；记录随本地账本备份，并受已启用的本地账本加密保护。API Key 只保存在设备安全存储中，不随备份导出。
- 添加账户时可填写 HTTPS 卡面图片地址；加载失败时显示默认图标。
- 可通过右上角菜单导出、恢复备份；恢复会替换当前账本；支持密码加密备份，未加密备份也可选择导出。
- 可选应用锁使用设备身份验证；应用锁不会加密本地账本。
- 账目保存在当前设备，不需要登录；默认不加密，可选择启用设备密钥保护的本地加密（实验性，尚未完成安卓真机验证）。启用前请导出备份；卸载应用、清除数据或丢失设备密钥可能导致账本不可恢复。目前没有云同步。

## 开发

需要 Flutter SDK 和 Android SDK。iOS 构建需要 macOS 和 Xcode。

```powershell
flutter pub get
flutter analyze
flutter test
flutter run
```

在此工作站，可以先运行 `. E:\DevEnv\Android\Enable-FlutterEnvironment.ps1`，再执行以上命令。

## 状态

Android 1.0.1 已在Android16 上验证覆盖安装和启动，启动图标与应用内标识均已更新。[下载最新 Android APK](https://github.com/DreamyXiam/FreeMyFinance/releases/latest)。iOS 仍需在 macOS 上构建验证。账户余额由初始余额和手工录入的账目计算，不连接银行，也不会自动同步交易。

### Android 正式签名

将 `android/key.properties.example` 复制为 `android/key.properties` 并填写自己的签名密钥信息，密钥文件及配置应妥善保管，不能提交到仓库。没有配置签名时，release 构建不会使用调试密钥。

## 卡面与卡号

- 卡面目录由提供的卡面清单生成，支持按卡组织、国家代码、发行方、卡类型和等级筛选。卡面图片从 AirCards 按需联网加载；图片及商标的权利属于相应权利人，使用和再分发须遵循来源方及权利人的授权。
- 储蓄卡和信用卡支持输入完整卡号。卡号保存在设备安全存储中，不包含在 JSON、CSV 或 Excel 备份与导出中；更换设备或清除应用数据后需重新输入。
- 可在汇率设置中使用接口盒子的个人 ID 和通讯密钥获取每日参考汇率；凭据仅按用户选择存储在设备安全存储中。数据不是实时汇率。
